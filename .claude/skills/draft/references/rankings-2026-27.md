# 2026-27 9-Cat 選秀排名

更新日期：2026-10-17（傷病狀態同日）。用於 12 隊、13 輪、H2H Each Category 的 9-cat 蛇形選秀。

- **價值**：9 個類別的 z-score 加總。FG%、FT% 依出手數加權；TO 越少分數越高。再依預估出賽數打折：72 場以上不打折，最低 0.55 倍。
- **ADP**：Rotowire 2026-27 9-cat 排名的順序，代表大約第幾順位會被選走。不是任何平台的即時 ADP。
- **數據來源**：2026-27 每場預估數據，是估計值，不是官方預測。
- **風險**：傷病或出賽數有問題的球員會在風險欄註明。一隊最多放 2 個。
- **強項 / 弱項**：z-score 最高的 3 類，以及 z-score 低於 -0.8 的類別。
- 括號格式：`(價值排名 / ADP)`。
